## 📱 프로젝트 소개
**NoSmoke**는 금연을 결심한 사람들을 위한 스마트한 동반자입니다. AI 상담사 '스털링'과 함께하는 맞춤형 상담, 재미있는 도전과제, 그리고 직관적인 건강 모니터링 기능을 통해 사용자의 성공적인 금연을 돕습니다.

### ✨ 핵심 가치
- 💪 **동기부여**: 게이미피케이션을 통한 지속적인 동기 부여
- 🤖 **AI 지원**: Gemini API 기반 맞춤형 상담 제공
- 📊 **데이터 기반**: 실시간 건강 개선 상태 시각화
- 🎮 **재미요소**: 도전과제와 보상 시스템

## 🎯 주요 기능
### 1. 금연 진행 현황 대시보드
- ⏱️ 금연 시작부터의 정확한 시간 추적
- 💰 절약된 금액 실시간 계산
- ❤️ 건강 개선 지표 시각화

### 2. AI 상담사 '스털링'
- 🤖 24/7 맞춤형 금연 상담
- 💬 실시간 동기부여 메시지
- 📋 과학적 근거 기반 조언

### 3. 도전과제 시스템
- 🎯 일일/주간 미션
- 🌍 환경 보호 연계 챌린지
- 🏆 업적 달성 보상

### 4. 커스터마이징
- 👤 프로필 꾸미기
- 🎨 테마 변경
- 🏅 특별 뱃지 콜렉션

## 🛠️ 기술 스택
- **Frontend**: Flutter
- **AI Engine**: Google Gemini API
- **상태관리**: Provider
- **데이터저장**: SharedPreferences

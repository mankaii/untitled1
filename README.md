## 🌟 소개

**NoSmoke**는 인공지능 기술과 과학적 접근법을 활용하여 사용자 맞춤형 금연 여정을 제공하는 스마트한 금연 도우미 앱입니다. 단순한 금연 앱을 넘어 개인에게 최적화된 디지털 웰니스 플랫폼을 지향합니다.

### 🎯 핵심 가치

- **목표 중심** - 명확한 금연 목표 설정과 달성 가능한 단계별 접근법 제시
- **AI 활용** - Google Gemini API 기반 24시간 맞춤형 금연 상담 서비스
- **데이터 기반** - 실시간 건강 지표 모니터링과 시각화로 동기부여
- **재미와 보상** - 게이미피케이션 요소로 꾸준한 앱 사용 독려

## ⭐️ 주요 기능

### 1. 스마트 대시보드
- ⏱️ 실시간 금연 타이머 
- 💰 금전적 절약 효과 계산기
- 📈 건강 개선 트래커

### 2. AI 금연 코치 '스털링'
- 🧠 개인 맞춤형 심리 상담
- 📚 과학적 금연 관련 정보 제공

### 3. 도전 과제 시스템  
- 🎯 맞춤형 단계별 금연 미션
- 🌍 달성을 통한 기부 등 사회 공헌
- 🏆 포인트 적립 및 보상 시스템

## 🚀 Getting Started

### 전제 조건

- Flutter 3.0 이상 
- Dart 2.17 이상
- Android Studio 또는 VS Code
- Google Gemini API 키

### 설치 및 실행

```bash
# 1. 저장소 클론
git clone https://github.com/Mseunghwan/no_smoke.git

# 2. 프로젝트 디렉토리로 이동
cd no_smoke

# 3. 종속성 설치
flutter pub get

# 4. 환경 변수 설정
cp .env.example .env
# .env 파일에 Google Gemini API 키 추가 

# 5. 앱 실행 (에뮬레이터 or 실기기 연결 상태)  
flutter run
```
